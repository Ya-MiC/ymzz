# Native product plugin / 原生產品插件

[`product`](product) is one private MIT DSH/Cordis workspace package: native brand/footer/theme extension points, pinned instruction skill registry, bounded task/gate tools using the real upstream agent/approval APIs, local-provider settings, manual diff review/memory and disabled-by-default signed-update staging. Native DSH chat/navigation/workspace/provider/tool/plugin functionality remains upstream, in its original layout.

No standalone runtime, replacement shell, Loop import or Tauri software is introduced. See product `PROVENANCE.json`, root README and exact evidence under `ymzz/docs/evidence`. Source/runtime tests pass; Windows desktop/GUI distribution is not yet qualified.
