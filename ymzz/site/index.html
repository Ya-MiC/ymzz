標籤面板

聊完的、查過的、做出來的，都留得下

面板長在原生右側工作區，跨會話存在。會話、可見的思考文字、查過的網頁、本機檔案與作品各自成條目，用多對多標籤與 Lists 彙編；星雲圖按頂級標籤分簇，同一條目可同時屬於多簇。寫入 Vault 需人工核准。

  • 01

    會話與思考

    從原生會話查詢讀標題與訊息，只取使用者訊息、助手回覆與待辦，不取隱藏推理鏈。標籤寫在本機帳本。

  • 02

    網頁來源

    瀏覽器擴展尚未隨包發佈，計劃預設裝在系統盤並附安裝引導。設計上只有你按下採集才寫一條記錄到本機，不讀瀏覽歷史、不整盤掃描。

  • 03

    作品與產出物

    本機檔案與產出物按路徑登記；雲端作品第一版只登記名稱與連結，不同步內容，雲端同步留給後續版本。

  • 04

    彙編與星雲

    像 Stars 與 Lists：標籤可交叉、可合併、可撤銷；星雲圖最多八簇，佈局確定性生成並支援減少動效。

此面板已寫入源碼並通過單元測試，Windows 圖形介面與安裝包尚未驗收。第一版不做雲端同步，後續版本再提供。

問題

先把容易誤會的話說清楚

可以下載 Windows / Mac / Linux 安裝包了嗎？
還不能。本產品沒有已驗收的公開安裝包。稟冊若有草稿安裝包，那是另一個軟體，而且部分下載頁需要 GitHub 登入。
那我現在怎麼用？
從 GitHub 取得原始碼，依開始頁的 Node、Git、pnpm 步驟在本機運行。未設定模型供應商時，不能說模型已經可用。
這與 Loop 是同一個產品嗎？
不是。Loop 是已完成的獨立專案管理產品。湛箴_ymzz 是完整 DSH 加插件的智能體發行版，只借鑑 Loop 官網的視覺風格；不匯入、不遷移、不取代。
資料會送到你們的伺服器嗎？
本官網不收集賬戶或對話。語言與主題只存在你的瀏覽器 localStorage。產品定位是本地優先、零遙測。你若自行設定雲端模型，那是你與該供應商的關係。
這是 DeepSeek 官方軟體嗎？
不是。它基於 MIT 授權的 DeepSeek Harness，由晏銘湛箴發行，不代表 DeepSeek 官方。
怎麼付費？
支付由作者自行接入，不在本站處理。本頁沒有收費方案，也沒有收款二維碼。
標籤面板會自動讀我的瀏覽紀錄嗎？
不會。沒有整盤掃描、沒有瀏覽歷史讀取、沒有雲端同步。網頁條目只在你於擴展按下採集時寫入本機帳本，且可逐條刪除。
資料存在哪裡？可以接到 Obsidian 嗎？
帳本在 DSH_HOME/ymzz 下的單一本機 JSON。核准後的筆記以 Obsidian 相容 Markdown 寫入你指定的 Vault，帶 YAML frontmatter 與雙鏈；未核准不會寫入，寫入後可撤銷。
Tauri 在這裡是什麼角色？
只是外殼：負責視窗、安裝、更新與啟停。內部仍然啟動完整 DeepSeek Harness，左側導航、中間對話、右側工作區、四套主題與原生功能面板都不重寫。
