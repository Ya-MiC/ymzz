現況據實：目前沒有已驗收、已公開的桌面安裝包。公開 Releases 現有 plugin-v0.1.0（插件包）與 v0.1.0-alpha.1（源碼階段預覽，無安裝包）。未驗收的桌面 canary 已改為 draft，不再作為公開下載入口。請先從原始碼運行。

首頁「取得」區的開發者通道只在你勾選允許後，才查詢公開的預發佈資產；它們不會出現在主按鈕上。目前沒有已公開的桌面 canary 安裝包。等一個版本通過真機點按驗收後，才會轉為正式發佈並自動出現在首頁。

2. 四步首次體驗

  1. 1

    現況

    目前沒有已驗收的桌面安裝包可下載。公開 Releases 現有 plugin-v0.1.0（插件包，不是桌面安裝程式）與 v0.1.0-alpha.1（源碼階段預覽，無安裝包）。請不要把 draft 資產、其他產品（含稟冊）的安裝包，或舊的 canary 檔名當成正式交付。

  2. 2

    現在如何使用

    請先依「開始」頁從原始碼運行。待已驗收的桌面安裝包以非 draft 的公開 Release 資產發佈後，再核對該頁提供的 SHA256 後安裝。目前沒有公開、已簽名的桌面安裝包；這不表示 Windows 桌面版已可正式發布。

  3. 3

    首次啟動

    首次打開會要求一個暱稱；模型金鑰可以選 Add API Key → Set up later 先跳過，沒有配置供應商時產品不會宣稱模型可用。之後在原生 Settings 配置模型與 MCP。

  4. 4

    體驗標籤面板並回饋

    右側「知識」標籤打開面板：設定 Vault（原生目錄選擇器）→ 從會話或手工文字建立草稿 → 審批 → 寫入 Obsidian Vault → 搜尋／星雲圖／撤銷。哪裡不行，到 GitHub issues 回報：附版本號、平台、截圖與重現步驟。

3. 回饋與邊界

  • 回饋入口：Ya-MiC/ymzz issues。使用原始碼運行時若有問題，請附版本號、平台、截圖與重現步驟。
  • 本頁不提供盜版、破解或第三方轉載下載；安裝包只來自本倉庫的 GitHub Releases。
  • 資料去哪：見隱私與 Cookie。產品零遙測；模型金鑰只保存在本機。

Summary (English)

There is currently no accepted, publicly downloadable desktop installer. Public Releases include plugin-v0.1.0 (a plugin tarball) and v0.1.0-alpha.1 (a source-only preview with no installer). Unreviewed desktop canaries were moved to draft and are not a public download. Please run from source first. This page does not claim that the Windows desktop edition is ready to ship.

First run: pick a nickname, skip the model key with "Add API Key → Set up later", configure model and MCP in native Settings, then open the 知識 dock on the right to set a Vault and turn a conversation into an approved Obsidian note. Report anything broken at the GitHub issues page with version, platform, screenshot and steps.
