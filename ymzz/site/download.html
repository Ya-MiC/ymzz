下載與首次啟動

第一位產品體驗者從這一頁開始

現況據實：正式（非預發佈）安裝包尚未發佈與驗收；canary 安裝包由 CI 自動構建，屬於預發佈資產，標注「未驗收」。你可以當第一位體驗者下載測試，並用 GitHub issues 回報。

1. 平台現況

平台格式狀態入口
Windows 10/11 x64 NSIS 安裝包（exe） canary · 未驗收 GitHub Releases
macOS（Apple Silicon） DMG canary · 未驗收 GitHub Releases
Linux x64 AppImage canary · 未驗收 GitHub Releases
任何平台 · 從原始碼運行 pnpm 源碼 目前真實入口 查看開始步驟

首頁「取得」區的開發者通道只在你勾選允許後，才列出標注「未驗收 canary」的預發佈資產；它們不會出現在主按鈕上。等一個版本通過真機點按驗收後，才會轉為正式發佈並自動出現在首頁。

2. 四步首次體驗

  1. 1

    下載

    到 GitHub Releases 的預發佈條目，選你平台的安裝包。canary 檔名形如 _ymzz_0.1.0_x64-setup.exe（Windows）與 _ymzz_0.1.0_aarch64.dmg（macOS）——打包器會把產品名中的中文字從檔名略去，屬預期；其他產品（含稟冊）的資產與本產品無關。

  2. 2

    核對後安裝

    安裝前先比對 Release 頁提供的 SHA256（canary 階段尚未配置代碼簽名，SmartScreen／Gatekeeper 可能提示未知發佈者，屬預期）。Windows 直接執行 NSIS 安裝程式；macOS 打開 DMG 拖入應用程式；Linux 賦予執行權限後運行 AppImage。

  3. 3

    首次啟動

    首次打開會要求一個暱稱；模型金鑰可以選 Add API Key → Set up later 先跳過，沒有配置供應商時產品不會宣稱模型可用。之後在原生 Settings 配置模型與 MCP。

  4. 4

    體驗標籤面板並回饋

    右側「知識」標籤打開面板：設定 Vault（原生目錄選擇器）→ 從會話或手工文字建立草稿 → 審批 → 寫入 Obsidian Vault → 搜尋／星雲圖／撤銷。哪裡不行，到 GitHub issues 回報：附版本號、平台、截圖與重現步驟。

3. 回饋與邊界

  • 回饋入口：Ya-MiC/ymzz issues。canary 階段的目標就是找出「哪裡不行」。
  • 本頁不提供盜版、破解或第三方轉載下載；安裝包只來自本倉庫的 GitHub Releases。
  • 資料去哪：見隱私與 Cookie。產品零遙測；模型金鑰只保存在本機。

Summary (English)

No stable installer is published yet. CI-built canary installers (NSIS / DMG / AppImage) are prerelease assets, labelled 未驗收 (not accepted), and listed only behind an explicit opt-in on the home page. Verify the SHA256 from the release page before installing; unsigned binaries may trigger SmartScreen or Gatekeeper warnings, which is expected for canary builds.

First run: pick a nickname, skip the model key with "Add API Key → Set up later", configure model and MCP in native Settings, then open the 知識 dock on the right to set a Vault and turn a conversation into an approved Obsidian note. Report anything broken at the GitHub issues page with version, platform, screenshot and steps.
