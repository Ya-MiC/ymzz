開始 · 目前真實入口

從原始碼運行

這不是安裝包下載頁。Windows / macOS / Linux 合格安裝包都還沒有。下面是倉庫 README 記載的真實上游入口；本 checkout 的完整桌面驗收尚未完成。

沒有附模型金鑰，未做 live／付費推論。產品啟動器直接運行完整官方 DSH CLI，預設獨立 ~/.ymzz（可用 YMZZ_HOME 指定）；設定端點不等於模型已驗證。

環境

你需要的東西

Node ≥ 24.9、Git ≥ 2.26，以及經 Corepack 啟用的 pnpm 11.28.5（以倉庫根目錄 packageManager 為準，不要自行改版號來宣稱相容）。

步驟

在倉庫根目錄執行

  1. 01

    取得原始碼

    git clone https://github.com/Ya-MiC/ymzz.git
cd ymzz
git checkout master
  2. 02

    安裝與建置

    corepack enable
pnpm install
pnpm run build:artifacts
  3. 03

    啟動（開發入口）

    pnpm exec node ymzz/scripts/dev.mjs --no-open --port 3081

    打開本機輸出的 3081 私人啟動連結，切勿公開驗證 token。這是原始碼運行，不是已驗收的桌面安裝包。
